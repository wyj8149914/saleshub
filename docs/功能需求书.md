# 库存管理系统功能需求书

## 一、系统概述

本系统为企业库存管理提供一站式解决方案，帮助企业实现库存件的信息化管理，支持常用件和设备件的分类管理，提供完整的入库、出库、库存查询和预警功能。

**适用对象：** 企业采购、销售、仓库管理人员

## 二、核心功能

### 2.1 产品管理

管理企业产品信息，并为产品配置关联的设备件。

**功能描述：**
- 创建、编辑、删除产品
- 为产品添加关联的设备件（一个产品可使用多个设备件）
- 产品信息包括：产品名称、产品编码、产品描述

### 2.2 库存件管理

管理企业的库存件，分为常用件和设备件两类。

#### 2.2.1 常用件管理

常用件是企业日常使用的通用零件，如螺丝、螺母、垫片等。

**功能描述：**
- 创建、编辑、删除常用件
- 为常用件配置规格选项（如：螺丝可配置"3mm、2.5mm、5mm"等规格）
- 常用件信息包括：名称、编码、规格选项、当前库存、预警库存

#### 2.2.2 设备件管理

设备件是专门用于特定产品的零件，一般不通用。

**功能描述：**
- 创建、编辑、删除设备件
- 将设备件关联到具体产品
- 设备件信息包括：名称、编码、关联产品、当前库存、预警库存

### 2.3 入库管理

将库存件入库，增加库存数量。

**功能描述：**
- 选择入库类型（常用件或设备件）
- 选择或创建库存件
- 填写入库信息：数量、入库日期、备注
- 上传入库照片（保存入库凭证）
- 系统自动增加库存数量
- 生成入库记录

### 2.4 出库管理

从库存中取出设备件，关联到具体产品。

**功能描述：**
- 选择出库产品
- 系统显示该产品关联的所有设备件
- 选择要出库的设备件
- 填写出库信息：数量、出库日期、备注
- 系统自动扣减库存数量（库存不足时允许继续出库）
- 生成出库记录

**说明：** 出库功能仅针对设备件，常用件不通过产品关联出库。

### 2.5 库存查询

实时查看当前库存状态。

**功能描述：**
- 查看所有库存件的当前库存数量
- 按类型筛选（常用件/设备件）
- 按产品筛选设备件库存
- 显示预警状态（库存低于预警值时标记）

### 2.6 库存历史

查看库存件的变动历史记录。

**功能描述：**
- 查看指定库存件的所有入库和出库记录
- 显示记录时间、数量、操作人员
- 支持按时间范围筛选

### 2.7 库存预警

自动提示库存不足的件。

**功能描述：**
- 系统自动检测库存低于预警值的件
- 在预警列表中显示所有预警项
- 显示预警件的当前库存和预警值
- 支持按严重程度排序

### 2.8 库存盘点

定期核对实际库存，修正系统库存数量。

**功能描述：**
- 选择要盘点的库存件
- 系统显示当前库存数量
- 输入实际盘点数量
- 系统记录盘点前后数量对比
- 生成盘点记录，更新系统库存

## 三、业务流程

### 3.1 入库流程

```
第一步：选择入库类型
   ├── 常用件入库
   └── 设备件入库

第二步：选择或创建库存件
   ├── 常用件：配置规格选项（如螺丝的3mm、2.5mm）
   └── 设备件：关联到具体产品

第三步：填写入库信息
   ├── 入库数量
   ├── 入库日期
   ├── 备注说明
   └── 上传照片

第四步：确认入库
   └── 系统增加库存，生成入库记录
```

### 3.2 出库流程

```
第一步：选择产品
   └── 从产品列表选择要出库的产品

第二步：选择设备件
   └── 系统显示该产品关联的所有设备件

第三步：填写出库信息
   ├── 出库数量
   ├── 出库日期
   └── 备注说明

第四步：确认出库
   └── 系统扣减库存，生成出库记录
```

### 3.3 盘点流程

```
第一步：选择库存件
   └── 从库存列表选择要盘点的件

第二步：查看当前库存
   └── 系统显示当前的账面库存

第三步：输入实际库存
   └── 输入盘点得到的实际数量

第四步：确认盘点
   └── 系统更新库存，生成盘点记录
```

## 四、数据说明

### 4.1 库存件分类

| 类型 | 说明 | 规格管理 | 产品关联 |
|------|------|----------|----------|
| 常用件 | 通用零件，如螺丝、螺母等 | 支持多规格选项 | 不关联产品 |
| 设备件 | 专用零件，仅用于特定产品 | 不需要规格 | 必须关联产品 |

### 4.2 库存预警

当库存件的当前库存数量低于或等于预警库存时，系统会在预警列表中提示，方便及时补货。

### 4.3 出库规则

- 出库仅针对设备件，通过产品关联进行
- 允许库存不足时继续出库（库存可能为负数）
- 定期通过盘点功能修正实际库存

## 五、用户角色

本系统主要面向以下人员使用：

| 角色 | 主要操作 | 说明 |
|------|----------|------|
| 采购人员 | 入库操作、库存查询 | 负责采购件入库，管理库存 |
| 销售人员 | 出库操作、产品管理 | 负责产品出库，配置设备件 |
| 仓库管理员 | 盘点操作、库存管理 | 负责定期盘点，维护库存数据 |

## 六、系统特点

1. **分类管理**：常用件和设备件分类清晰，管理规范
2. **产品关联**：设备件与产品强关联，出库操作便捷
3. **灵活规格**：常用件支持多规格管理，适应不同需求
4. **图片凭证**：入库支持上传照片，留存凭证
5. **智能预警**：库存不足自动提醒，避免缺货
6. **历史追溯**：完整的出入库记录，便于追溯
7. **盘点修正**：支持定期盘点，确保库存准确
