# 仓库管理前端设计文档

## 一、需求概述

### 业务背景
后端已实现仓库管理功能，零件入库时需要选择入库到哪个仓库，同一个零件同规格可以入库到不同仓库。

### 核心需求
1. **入库流程**：每次入库手动选择仓库，批量入库时先选仓库再添加零件明细
2. **出库流程**：出库时必须指定从哪个仓库出，显示可用库存
3. **库存查看**：零件视角查看仓库分布 + 仓库视角查看库存明细
4. **仓库管理**：仓库的增删改查，删除时校验是否有库存

### 用户决策记录
- 入库时每次都手动选择仓库（方案A）
- 批量入库时所有零件入库到同一仓库，先选仓库再添加零件
- 库存查看需要两种视角：零件视角和仓库视角
- 出库时需要选择从哪个仓库出库
- 库存预警按零件总库存判断，不区分仓库

## 二、入库功能设计

### 2.1 单条入库界面

```
┌─────────────────────────────────────────┐
│ 入库                                     │
├─────────────────────────────────────────┤
│ ◉ 单条入库  ○ 批量入库                   │
│                                          │
│ 仓库 *                                    │
│ [下拉选择仓库 ▼]                          │
│                                          │
│ 入库日期 *          数量 *                │
│ [日期选择器]        [数字输入框]          │
│                                          │
│ 零件 *              规格                 │
│ [下拉选择零件 ▼]    [下拉选择规格 ▼]      │
│                                          │
│ 入库照片                                  │
│ [上传区域]                               │
│                                          │
│ 备注                                      │
│ [文本框]                                 │
└─────────────────────────────────────────┘
```

**字段说明**：
- 仓库：必填，下拉选择，只显示状态正常的仓库
- 入库日期：必填，默认今天
- 数量：必填，整数 ≥ 1
- 零件：必填，下拉搜索选择
- 规格：零件有多规格时必填，单规格自动填充
- 入库照片：可选，最多1张
- 备注：可选，最多500字

**交互逻辑**：
1. 选择仓库后，零件选项加载所有零件（不按仓库过滤）
2. 选择零件后，规格下拉显示该零件所有规格，单规格自动填充
3. 提交时调用后端入库接口，仓库ID传入后端


**布局说明**：
- 顶部区域：仓库、日期、照片、备注（整批共用）
- 入库明细区：动态添加多行零件明细

**交互逻辑**：
1. 仓库选择在顶部，对所有零件明细生效
2. 每行选择零件后，自动显示规格下拉（单规格自动填充）
3. 数量默认为1，可修改
4. 至少保留一行明细
5. 同一零件+规格不能重复添加

**校验规则**：
| 字段 | 规则 | 提示信息 |
|------|------|----------|
| 仓库 | 必填 | "请选择仓库" |
| 入库日期 | 必填 | "请选择入库日期" |
| 零件 | 每行必填 | "第N行未选择零件" |
| 规格 | 多规格必填 | "第N行未选择规格" |
| 数量 | 必须 ≥ 1 | "第N行数量无效" |
| 重复 | 同一零件+规格不能重复 | "入库列表存在重复的零件规格" |

## 四、库存查看功能设计

### 4.1 零件视角 - 零件详情弹窗

在零件列表操作列增加"详情"按钮，点击弹出：

```
┌────────────────────────────────────────────────────┐
│ 零件详情                                            │
├────────────────────────────────────────────────────┤
│ ──── 基本信息 ────                                  │
│ 零件名称: 螺丝          编码: BOLT-001              │
│ 零件类型: 五金件 > 紧固件   是否定制: 否             │
│ 预警库存: 50            备注: -                     │
│                                                     │
│ ──── 规格信息 ────                                  │
│ 规格名称    价格      总库存                         │
│ ─────────────────────────────────────              │
│ ▶ M8×30      ¥0.50      100                        │
│ ▼ M10×40     ¥0.80       80                        │
│     ┌─────────────────────────────────────┐        │
│     │ 仓库名称   位置        库存数量      │        │
│     │ 仓库A      A栋1层        60         │        │
│     │ 仓库B      B栋2层        20         │        │
│     └─────────────────────────────────────┘        │
│                                                     │
│ 总库存: 180                                         │
└────────────────────────────────────────────────────┘
```

**布局说明**：
- **基本信息区**：零件的基础属性（名称、编码、类型、是否定制、预警库存、备注）
- **规格信息区**：表格展示所有规格概览（规格名称、价格、总库存）
- **库存分布详情**：点击规格行展开查看该规格在各仓库的分布（仓库名称、位置、库存数量）
- **总库存**：底部显示该零件所有规格的总库存

**接口调用**：
- 零件基本信息：复用现有的 `listItems` 接口数据
- 规格仓库分布：调用 `listSpecWarehouseStock` 接口，传入 `spec_id`

## 五、数据校验与错误处理

### 5.1 入库校验

| 场景 | 校验规则 | 提示信息 |
|------|----------|----------|
| 选择仓库 | 仓库必须存在且状态正常 | "仓库不存在或已停用" |
| 选择零件/规格 | 零件和规格必须存在 | "零件不存在" / "规格不存在" |
| 入库数量 | 必须 ≥ 1 | "数量必须大于0" |
| 批量入库 | 同一零件+规格不能重复 | "入库列表存在重复的零件规格" |

### 5.2 出库校验

| 场景 | 校验规则 | 提示信息 |
|------|----------|----------|
| 选择仓库 | 仓库必须存在且状态正常 | "仓库不存在或已停用" |
| 零件库存 | 该零件在该仓库必须有库存 | "该零件在此仓库无库存" |
| 出库数量 | 不能超过可用库存 | "出库数量超过可用库存(N)" |
| 批量出库 | 同一零件+规格不能重复 | "出库列表存在重复的零件规格" |

### 5.3 仓库删除校验

| 场景 | 校验规则 | 提示信息 |
|------|----------|----------|
| 删除仓库 | 仓库不能有库存 | "该仓库存在库存，无法删除" |

## 九、注意事项

1. **性能优化**：仓库库存明细展开时，建议按需加载，避免一次性加载所有仓库数据
2. **用户体验**：出库时选择仓库后，零件下拉应只显示有库存的零件，避免选择后提示无库存
3. **数据一致性**：入库/出库操作后，应及时刷新相关库存显示
4. **权限控制**：仓库管理功能应考虑权限控制（后续可扩展）
