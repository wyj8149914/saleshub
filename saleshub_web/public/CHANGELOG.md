# SalesHub Web 更新日志

本文档记录 SalesHub 前端（saleshub_web）的版本变更。格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

---

## [0.14.0] - 2026-11-01

### 新增

- **销售订单模块**
  - 订单列表：筛选、分页、删除
  - 新建/修改订单，详情抽屉查看完整信息与合同文件
  - 收款登记：记录本次收款金额，校验不能超过未收金额
  - 状态变更：支持标记已取消（终态不可再变更）

- **用户管理**
  - 用户列表、新建/修改用户、修改密码、启用/停用
  - 管理员角色专属菜单，普通用户不可见

- **费用与发票增强**
  - 费用关联发票支持选择已有未绑定发票，无需重复上传
  - 发票与支出费用列表新增删除功能

### 改进

- **用户表单校验优化**
  - 密码强度、手机号格式校验改为失去焦点触发，错误信息显示在输入框下方
  - 新建用户需二次输入确认密码，校验两次输入一致
  - 手机号选填，填写时校验 11 位大陆手机号格式

### 技术

- 迁移 ESLint 至 v10，消除代码中的 `any` 类型
- 按最新 Prettier 规则统一格式化组件模板与代码

---

## [0.13.0] - 2026-10-31

### 新增

- **支出费用模块**
  - 费用单列表、新建、修改与详情查看
  - 采购明细多行编辑：一级/二级类型、零件、规格、数量、单价，行金额自动汇总
  - 空行提交时自动忽略，金额支持从明细自动填充
  - 关联发票：为费用单上传识别新发票并绑定，支持换绑（旧发票自动释放）
  - 费用名称与电商订单号字段

### 技术

- 后端支出费用与发票服务迁移至 finance 模块，新增费用接口文档

---

## [0.12.0] - 2026-10-30

### 新增

- **业财管理页面**
  - 新增业财管理菜单：发票管理、支出费用、销售订单页面入口
  - 发票列表与详情查看，支持标签管理

- **发票报税**
  - 报税筛选、报税状态列展示
  - 批量报税与取消报税，选中含已报税行时拒绝操作

### 改进

- 报税操作布局优化，支持选中行金额汇总
- 库存列表横向滚动布局，移除发票源文件独立页面
- 产品列表样式优化

## [0.10.0] - 2026-08-18

## [0.9.0] - 2026-07-07

### 新增

- **产品详情查看功能**
  - 产品列表新增「详情」按钮，点击弹窗展示产品完整信息
  - 顶部展示产品基本信息（名称、编码、描述、价格、备注）
  - BOM 清单表格展示模块和零件结构
  - 模块模式下第一列合并展示产品名称，第二列按模块合并，后续展示零件详情
  - 直接关联模式下不显示模块列，表格更加简洁

- **后端产品详情接口**
  - 新增 `/saleshub/inventory/productDetail` 接口
  - 聚合返回产品基础信息及 BOM 零件结构
  - 根据零件管理方式返回不同结构（module/direct/none）

### 改进

- **模块零件编辑器交互优化**
  - 添加/删除零件改为本地数据修改，不再立即调用接口
  - 新增「保存」按钮，点击后统一提交该模块零件
  - 支持变更检测，无修改时保存按钮禁用
  - 移除父组件对模块零件的实时同步，数据流更加清晰

- **接口优化**
  - `setProductItems` 和 `setModuleItems` 支持空数组清空零件
  - 清空时自动将关联记录状态置为无效

### 技术

- 新增 `ProductDetail.vue` 产品详情组件
- 新增 `ProductDetailResponse` 等类型定义
- 新增 `getProductDetail` API 方法
- 重构 `ModuleItemsEditor.vue` 本地数据管理逻辑
- 更新 API 接口文档

---

## [0.8.0] - 2026-07-05

### 新增

- **入库/出库记录撤销功能**
  - 入库记录列表新增撤销按钮，支持撤销入库操作并回退库存
  - 出库记录列表新增撤销按钮，支持撤销出库操作并恢复库存
  - 后端新增 `revertStockIn` 和 `revertStockOut` 接口

### 改进

- **类型选择交互优化**
  - 入库、出库、盘点弹窗及库存历史页面：零件选择不再强制要求先选类型
  - 用户可直接选择任意零件，选择类型后自动筛选零件列表
  - 批量入库/出库/盘点时，每行可独立选择类型和零件
  - 移除二级类型下拉框的禁用状态，支持自由选择

### 技术

- 重构 `useStockFilter` composable，支持直接加载所有零件并按类型筛选
- 重构 `StockInModal`、`StockOutModal`、`StockCheckModal` 组件的类型选择逻辑
- 新增 `allItemsUnfiltered` 状态存储未筛选的零件列表

---

## [0.7.0] - 2026-07-01

### 新增

- **零件类型管理系统**
  - 新增类型管理界面（`ItemTypeManager` 组件），支持新增、编辑、删除零件类型
  - 树形展示一级类型和二级类型，层级关系清晰
  - 零件表单支持二级联动选择类型：先选一级类型，再选二级类型
  - 零件列表支持按一级、二级类型筛选

- **产品价格功能**
  - 产品表单新增价格字段，支持输入产品价格
  - 产品列表显示价格列，方便快速查看产品定价
  - 价格字段支持两位小数，最小值为 0

- **零件规格价格**
  - 零件规格新增价格字段，支持为不同规格设置不同价格
  - 库存列表展开显示规格价格信息

### 改进

- **库存项字段增强**
  - 新增价格、备注、定制属性等字段
  - 完善字段验证规则，提升数据质量

- **界面优化**
  - 类型管理表格优化为树形展示，层级关系更清晰
  - 更新登录页与侧边栏版权信息

### 技术

- 新增零件类型相关 TypeScript 类型与 API 封装（`ItemTypeNode`、`ItemTypeCreatePayload` 等）
- 重构 `InventoryItemForm` 组件，适配二级类型选择
- 新增 `ItemTypeManager.vue` 类型管理组件

---

## [0.6.0] - 2026-06-26

### 新增

- 盘点管理：盘点记录列表，支持按单号、日期筛选；单条/批量盘点弹窗，修正实际库存
- 入库管理重构：入库记录列表，单条/批量入库，支持入库照片上传
- 出库管理重构：出库记录列表，按零件单条/批量出库，支持按产品 BOM 出库
- 顶部栏版本号与更新日志入口，点击在当前页面弹窗中查看 `changelog.html`

### 改进

- 库存历史：盘点记录的变更数量按 `after_stock - before_stock` 计算，统一 +/- 符号与红绿灰颜色区分
- 日期选择器全局中文：配置 dayjs `zh-cn` locale，月份与星期显示为中文
- 侧边栏新增「盘点管理」菜单项

### 技术

- 新增盘点相关 TypeScript 类型与 API 封装（`stockCheck`、`stockCheckBatch`、`listStockCheckRecords`）
- 新增 `src/constants/app.ts` 集中管理应用版本号

## [0.5.0] - 2026-06-25

### 新增

- 零件与产品支持图片上传，可在表单中预览与管理图片
- 常用件支持多规格管理，库存按规格维度独立统计
- 新增 `upload.ts` 图片上传工具，内置类型与大小校验（默认最大 10MB）

### 改进

- 重构 `InventoryItemForm`、`ProductForm`、`ProductItemsManager` 组件，适配规格级库存
- 优化 `SpecEditor` 规格编辑器交互
- 零件列表支持按规格展示库存数量
- 库存历史记录关联规格信息

## [0.4.0] - 2026-06-18

### 变更

- 统一业务术语：「零部件」统一为「零件」，与后端及数据库命名保持一致
- 重构入库、出库、库存历史页面，优化表单与列表交互
- 精简库存管理 API 接口定义，移除冗余调用

### 移除

- 侧边栏移除「库存预警」菜单入口（路由保留，可直接访问 URL）

## [0.3.0] - 2026-06-18

### 新增

- 登录页对接后端认证接口，支持账号密码登录与 Token 持久化
- 产品管理：产品列表、新建/编辑产品、关联零件管理
- 零件管理：零件列表、新建/编辑零件（设备件 / 常用件）
- 入库管理：选择零件与数量，记录入库操作
- 出库管理：选择零件与数量，校验库存后出库
- 库存历史：查看出入库流水记录
- 主布局 `DefaultLayout`：侧边栏导航、顶部用户信息、退出登录
- `ProductItemsManager` 组件：管理产品与零件的关联关系

### 改进

- 完善路由鉴权，未登录自动跳转登录页并保留重定向地址
- 统一 Axios 请求封装与错误处理
